## How to use this plan

Ask the agent: **"Implement DLG-1.1"** (or several). The agent must:

1. Read [`progress.md`](./progress.md) for state, blockers and decisions.
2. Read the task entry and every referenced spec, plus [`specs/00-architecture.md`](./specs/00-architecture.md).
3. Check that every **Depends on** task is `done`; otherwise stop and report.
4. Implement within scope; record deviations in progress.md.
5. Run the Definition of done.
6. Update progress.md: status table, session log, pending manual checks.

### Definition of done (every code task)

- `npm run lint` (includes style-drift) and `npm run typecheck` pass; targeted vitest for touched logic.
- New pure logic has unit tests in `tests/unit/`.
- New strings exist in `i18n/locales/en.json` and `i18n/locales/zh-CN.json`.
- Editor/public parity preserved (same classes, shared CSS).
- The task's items in [`acceptance-test.md`](./acceptance-test.md) pass or are listed as pending.
